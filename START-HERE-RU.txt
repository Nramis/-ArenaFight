Сохранённая версия сайта: 2
Коммит исходников: 2873d0c9dd4c438b429a702685a0ce9e8d4c07b1

В архиве исходники Godot (game/), сервер комнат и сеть (net/, app/),
веб-интерфейс и готовая браузерная сборка (public/), изображения и звуки.
Это экспорт сохранённого коммита, с которым опубликована версия 2 сайта.
Зависимости, локальные базы и временные файлы не включены.

КАК ПЕРЕНЕСТИ В СУЩЕСТВУЮЩИЙ GITHUB-РЕПОЗИТОРИЙ
1. Клонируйте https://github.com/Nramis/-ArenaFight.git на свой компьютер.
2. В папке репозитория создайте ветку: git switch -c feat/rinat-skins-export
3. Скопируйте СОДЕРЖИМОЕ папки ArenaFight-Rinat из архива в корень
   репозитория. Скрытые файлы, включая .gitignore и .openai, тоже нужны.
   Не удаляйте и не заменяйте существующую папку .git репозитория.
4. Проверьте git status и git diff: архив соответствует опубликованной
   версии 2; более новые изменения других веток нужно сохранить отдельно
   и совместить при проверке различий. Простое копирование не удаляет
   устаревшие файлы, поэтому не считайте его автоматическим слиянием.
5. git add -A
6. git commit -m "Add Rinat and fighter skins from published version 2"
7. git push -u origin feat/rinat-skins-export
8. Откройте Pull Request в GitHub и проверьте изменения перед слиянием.

Запуск и сборка описаны в README.md. Для редактирования боевой части
откройте game/project.godot в Godot версии 4.7.2. После правок Godot
нужен новый Web-экспорт и запуск compress-web.py — pnpm dev сам по себе
не пересобирает игровые скрипты в браузерную сборку.
