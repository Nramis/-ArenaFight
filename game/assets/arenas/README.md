# Arena backgrounds

`taneko.png` and `office.png` were generated with the built-in image generator for this game. These are fictional stylized environments inspired by a refinery and a modern corporate office, rather than architectural reproductions.

Generation brief: wide side-view 2D fighting game arena, detailed cel shaded illustration, clear flat foreground combat floor, no people, no UI or lettering. Refinery: dusk sky, pipes, distillation towers, warm industrial lights, blank central sign. Office: green accented modern corporate lobby, windows, reception and blank sign panel. Native game rendering adds the Russian venue names and places the floor at the gameplay baseline.
