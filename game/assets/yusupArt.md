# Юсуп

`yusup.png` — оригинальный прозрачный атлас, созданный встроенным ImageGen по предоставленной пользователем фотографии. Исходный PNG скопирован без изменений в `public/portraits/yusup.png`. Сохранены очки в чёрной оправе, короткие тёмные волосы, чёрные худи и брюки. Для «Плавунца» используется синий спортивный купальный костюм.

Размер атласа: 1254 × 1254, четыре столбца и четыре ряда. Позы по строкам:

- стойка, два шага, удар рукой;
- удар ногой, прыжок, приседание, получение удара;
- начало разговора, отмахивание, поднятый пульт, подготовка к плаванию;
- четыре последовательные фазы мельницы руками в купальном костюме.

`fighter/yusupArt.gd` хранит UV-границы и изолирует поднятую руку последней позы без изменения исходного растра. Внешность используется только как визуальный референс; голос с фотографии не воспроизводится.
